# Benign Overfitting with Quantum Kernels
This repository provides the code used for the numerical experiments in:

[1] Joachim Tomasi, Sandrine Anthoine, Hachem Kadri. "*Benign Overfitting with Quantum Kernels*". UAI 2026.

The directory contains all numerical experiments, described in Appendix F, of the paper. The implementation is written in Python.


The figures, appearing in Section 4 and in Appendix F,  can be reproduced by running `All_Figures.ipynb`.

The tables, appearing in Appendix F,  can be reproduced by running `All_Tables.ipynb`.
